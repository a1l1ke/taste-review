# SRS 목록

이 디렉터리는 taste-review의 SRS(Software Requirements Specification)를 관리한다.
새 SRS는 `/srs` 스킬로 작성하며, 형식은 `.agents/skills/srs/template.md`를 따른다.

- 파일 이름: 원본 PRD와 같은 번호와 슬러그를 쓴다 (`PRD-001-foo.md` → `SRS-001-foo.md`).
- 상태: `Draft` → `Review` → `Approved`, 폐기 시 `Deprecated` (파일은 삭제하지 않음)
